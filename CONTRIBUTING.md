# Contributing

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Contributions Welcome

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Before making a contribution, please ensure that your changes are clear, useful, and relevant to the project.

## Bug Reports

If you find a bug, please describe the problem clearly and provide enough information to reproduce it.

## Bug Fixes

Bug fixes are welcome. Please explain what was changed and how the fix addresses the problem.

## Documentation Improvements

Improvements to documentation, examples, and explanations are encouraged.

## Enhancements and Ideas

Suggestions for new features, improvements, and other ideas are welcome. Please describe the proposed change and its benefits.

## Code Contributions

Please keep contributions simple, readable, and consistent with the existing project.

Thank you for contributing!
